# Repository Structure

The existing source tree reflects the verified architecture and current reconstruction workflow of this project. Do not rename or reorganize established directories merely to resemble another generation or repository.

- preserve established build paths and include/import relationships;
- retain existing `docs/`, graphics/assets, symbols, tools, manifests, and other real project material;
- add directories only when they contain real project material;
- keep target-specific differences close to relevant source or metadata;
- document structural changes that affect builds, extraction, symbols, or matching.

When proposing a major restructure, explain the migration, build impact, and verification plan first.
