# Ruby public graphics catalog

The catalog inventories all 165 files currently stored below `graphics/`: 112 rendered PNG assets, 53 JASC palettes, and 0 JSON sidecars. Each entry records its full hash and points to the pre-existing ROM-derived analysis or manifest that establishes provenance. `ASSETS.md` supplies a browsable GitHub preview.

The catalog does not infer a language when the filename does not declare one, and it does not embed ROM bytes.
